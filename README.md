# Psivi 桌面试用版

Psivi 是在 Mac 上使用的本地项目助手，安装后显示为 **Psi Trial**。当前试用版适用于 Apple Silicon（M 系列芯片），需要 macOS 13 或更新版本。

在[版本下载页](https://github.com/weiliang0121/psi-releases/releases)选择最新预览版，下载附件中的 `.dmg`。如果已安装旧版，先退出 Psi Trial，再打开镜像，将应用拖入「应用程序」替换旧版。首次使用请在设置中填写自己的模型连接和 API Key。

每个版本的发布页都列有改动、签名和公证状态，并附有中文试用指南和 SHA-256 校验文件。
